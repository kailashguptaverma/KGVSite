01

Overview

My CSE 3300 coursework explores how browser interfaces, server-side programs, databases, and cloud hosting work together. Across Modules 1–4, the work progresses from a static birthday page to applications with user accounts, persistent content, and asynchronous updates. This collection includes nine projects and exercises, with both individual work and collaborative applications.

02

My contribution

I completed the individual HTML/CSS, calculator, SQL, weather-widget, and Connect Four debugging exercises, and collaborated on the file-sharing, news, and calendar applications. My work across the collection involved interface development, PHP request handling, database queries, authentication flows, styling, troubleshooting, and EC2 deployment.

03

Design & development

Birthday Card & Search Portal

01 / Module 1 / Individual | HTML · CSS · DOM events

Created a birthday page for my dog, Baloo, with a photo gallery, a compliment form, and animated messages. A separate DuckDuckGo search portal introduced browser form submission. This project connected semantic HTML, external stylesheets, simple JavaScript interactions, Git, and early AWS setup.

Server-Side Calculator

02 / Module 2 / Individual | PHP · GET forms · PHPUnit

Built a four-operation calculator using an HTML form and a reusable PHP calculation function. The implementation handles division by zero and invalid operations. The repository also includes PHPUnit test cases for arithmetic and error paths, giving the calculation logic a way to be checked separately from the page.

Try PHP calculator ↗

File-Sharing Website

03 / Module 2 / Group | PHP · Sessions · File handling · Apache

Collaborated on a login-based file-sharing site with upload, open, delete, and logout workflows. Case-insensitive search and natural alphabetical sorting help users find their files. The project involved coordinating PHP endpoints, session state, upload checks, per-user storage, and deployment on an AWS EC2 instance.

Explore file-sharing site ↗

Community News Website

05 / Module 3 / Group | PHP · MySQL · Authentication · Voting

Collaborated on a database-backed news site with registration, login, articles, comments, and voting. Users can edit or delete their own content, and vote totals drive score-based sorting and a top-three trending section. Prepared statements, password hashing, CSRF checks, and ownership checks are used across the application.

Explore news website ↗

Live JavaScript Calculator

06 / Module 4 / Individual | JavaScript · Event listeners · DOM updates

Recreated the calculator in the browser so results update when either number or the selected operation changes. The exercise focused on converting input strings into numbers, reading radio-button state, handling arithmetic edge cases, and updating an existing result element without a page refresh.

Try JavaScript calculator ↗

AJAX Weather Widget

07 / Module 4 / Individual | Fetch · JSON · Asynchronous JavaScript

Built a weather widget that requests JSON from the course weather endpoint and fills existing page elements with weather information and an image. Debugging focused on promise return values, nested JSON properties, and matching DOM lookups to the actual HTML structure.

View weather widget ↗

Connect Four Debugging

08 / Module 4 / Individual exercise | JavaScript · Game state · Boundary checks

Diagnosed and corrected a supplied Connect Four implementation. The work addressed turn switching, piece placement, initialization, and win and draw logic. Reviewing horizontal, vertical, and diagonal checks made array bounds and the order of state updates especially important.

Play Connect Four ↗

Personal AJAX Calendar

09 / Module 4 / Group | JavaScript · PHP · MySQL · JSON endpoints

Collaborated on a monthly calendar with account-based events that can be added, edited, and deleted without refreshing the page. Additional features include category filters, completion tracking, and an upcoming-events list. PHP endpoints handle stored events and ownership checks, while request counters help prevent older asynchronous responses from replacing newer results.
